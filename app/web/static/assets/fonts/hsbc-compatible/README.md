# Code version: v0.2.0

Place licensed webfont files in this directory.

Bundled Univers Next reserve:

- `UniversNextforHSBCW01-UltLt.ttf` maps to `font-weight: 100`
- `UniversNextforHSBCW01-UtLtI.ttf` maps to `font-weight: 100; font-style: italic`
- `UniversNextforHSBCW01-Th.ttf` maps to `font-weight: 200`
- `UniversNextforHSBCW01-ThIt.ttf` maps to `font-weight: 200; font-style: italic`
- `UniversNextforHSBCW01-Lt.ttf` maps to `font-weight: 300`
- `UniversNextforHSBCW01-LtIt.ttf` maps to `font-weight: 300; font-style: italic`
- `UniversNextforHSBCW01-Rg.ttf` maps to `font-weight: 400`
- `UniversNextforHSBCW01-Md.ttf` maps to `font-weight: 500` and `600`
- `UniversNextforHSBCW01-Bd.ttf` maps to `font-weight: 700`

Optional compatible filenames:

- `UniversNextforHSBCW02-Rg.ttf`
- `HelveticaNeueforHSBCW84-Rm.woff2`
- `HelveticaNeueforHSBCW84-Lt.woff2`
- `HelveticaNeueforHSBCW84-Md.woff2`
- `HelveticaNeueforHSBCW84-Bd.woff2`

Only add files that are licensed for self-hosted web use in this app.
